# v3.51.1

## 新增功能

- 快乐首字：合并独立分支，支持按 Client Key 白名单或全部 Key 发送 `gateway.status.delta`，默认关闭，提示延迟可配置并支持热保存
- 账号瞬时流量保护：对所有新老账号按实际发送次数共享限速，支持突发额度、每秒速率和有界等待，覆盖 HTTP、WS 每轮请求及受管插件转发，默认关闭
- 新号独立并发保护：不依赖老号存活或交接配对，支持分阶段放量，覆盖手动导入和插件导入
- 多账号交接组：支持指定承接关系、多老号共享少量新号的保护额度，新号加入后重分配名额，并结合额度与时间选择待交接账号
- 额度桶设置：保留已有额度调度上限，新增通用额度桶重置后的可选预热
- 插件额度观测：按账号、额度桶和时间范围分页读取留存历史，包含区间起点基线

## 优化改进

- 合入官方 v3.50.0 与 v3.51.0，支持管理端 URL 子路径部署、统一操作菜单键盘交互及更紧凑的用量筛选
- 账号列表展示实际新号保护与交接限制，手动交接页面统一配置保护和承接关系
- 调度插件可识别会话绑定、优先候选、跟随绑定与固定选号，继续由宿主校验权限和租约

## 问题修复

- 代理入口明确不可达时，同一请求后续跳过共用该入口的账号，避免反复拨号
- WS 瞬时建连失败遵守换号次数与共享建连预算，原生续接遇到过长容量等待时可迁移绑定并要求客户端完整历史重放
- 无状态码的流内 `invalid_request_error` 按请求错误分类，严格会话绑定的模型权限等待超时给出明确原因
- 连接关闭测试使用真实时钟并区分正常 EOF 与取消后的 TCP 重置，减少跨平台误失败

## 升级须知

- 从二开 v3.49.2 升级会执行新增迁移 `0046_account_quota_settings.sql`，保留原额度上限，桶预热默认关闭；升级前备份数据库、配置和 Redis 持久数据
- 既有交接参数保留，新号独立保护与交接组需显式启用，不因升级自动采用新策略
- 快乐首字只用于符合条件的 OAuth Responses SSE，不代表模型出字或成功，不增加模型用量，也不加快推理；可能影响下游 TTFT 口径和重试，启用前验证客户端
- 瞬时保护限制请求发起速率，不替代并发上限或上游限流退避，也不保证消除所有 429
- 调度插件 `scheduler` 能力升级至 v4，使用 v3 的调度插件需适配后使用；独立补号插件不在本次主程序发行包中
