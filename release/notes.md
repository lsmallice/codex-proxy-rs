# v3.52.2

## 新增功能

- 同步官方 v3.52.1，补齐 GPT-6.2 系列参考价目，用量列表区分 Fast 与 Ultrafast 标识
- 用量筛选：支持按请求历史中的账号名称或邮箱搜索

## 优化改进

- 交接余量：一对一和多账号交接在减载前为新增流量预留空间，扣除新号占用与老号尚未排空的请求，避免把承接容量全部占满
- 容量恢复：池子余量不足且老号仍健康时，每五秒最多恢复一档已减载容量，不超过交接前基线及管理员上限，稳定后继续向原保留值减载
- 账号查询：支持按原始导入时间筛选，在数据库分页和额度、用量投影前缩小查询范围，省略筛选时保持原行为
- 模型目录：正常响应的 ETag 与已保存目录一致时延后复查，减少重复查询
- 套餐展示：Business、Enterprise 和科研套餐沿用 Codex 名称，长名称在表格内换行

## 问题修复

- 并发释放：上游流结束、出错或取消后及时归还账号槽位，不再等待费用和请求记录结算
- WS 轮次状态：按当前请求转发路由状态和元数据，握手轮次头仅用于首帧，明确换号时清除原账号状态
- 保护解除：明确完成新号保护后，交接组不再残留保护档位上限，恢复账号原始并发设置；状态未知时继续保护
- 承接均衡：不限并发的接收账号使用合理负载参考参与均衡，不因极大容量值持续优先于其他新号
- 观测连续性：观测中断或时钟回退时保持当前档位并重新观察，避免把时间空白当作稳定窗口

## 升级须知

- 无新增数据库迁移或必填配置，沿用现有交接开关、保留值、步长和保护参数，未开启交接的实例不会自动开启
- 外部调用用量明细筛选时，将 accountName 改为 accountSearch，管理页面已同步适配
- 保留新号并发保护、发送限速、会话粘性与固定续接规则；总需求超过安全容量时仍可能排队或超时
- 保留 IPv6 分配、Lite 兼容、可选首字通知及有界 WS 恢复，现有开关不自动开启
- 本版只提供导入时间筛选接口，补号插件的三小时扫描优化需要单独更新插件，不随 CPR 镜像安装
- 包含尚未公开的 v3.51.4 交接优化，无需先安装该版本
- 保留已批准的 picomatch GHSA-fc5q-39xc-vjpf 构建依赖单项审计例外，其他安全检查不变
- 本次仅发布 CPR，不升级或重启线上实例，不更新线上插件
