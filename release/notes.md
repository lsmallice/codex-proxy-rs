# v3.43.1

## 新增功能

- 管理端主题：合并官方 v3.43.0 的四套场景预设与默认、柔光材质，侧栏采用 UI v0.9.0 共用组件
- 插件管理页：打开 HTTPS 外链前由宿主展示确认框，支持打开、复制或取消

## 优化改进

- 系统更新：采用官方 main 分支发布通道表，保留二开和官方来源查询及只读切换预检
- 模型目录：普通 API Key 模型列表中的已知生图、实时语音和语音合成模型不再混入默认 Agent 选模列表，直接调用不受影响
- 管理端：移除重复悬浮提示，保留截断文本全文和错误详情

## 问题修复

- 账号调度：正常停机时有界释放本实例持有的普通池及审批池并发占位，不清理其他实例租约
- 账号调度：排队失败后成功迁移绑定时记录原账号、新账号和原因
- OAuth 导入：保留代理 WS 容量配置，避免授权状态往返后丢失
- 账号列表：修复桌面端可容纳内容时仍出现整页滚动条的问题

## 升级须知

- 基于官方 v3.43.0，保留二开的会话备用 WS 预连接、403 握手恢复、断流和解密恢复、原生请求兼容、模型冷却与热配置
- WS 预连接仍默认关闭，已保存的二开配置保留，不能保证消除 403，未知会话通用空连接池与 100+ 并发验证不在本次范围
- 从二开 v3.42.4 升级无数据库迁移变化，升级前仍须备份数据库、配置、插件及运行目录
- 新版更新器读取本仓库 main 的通道表，旧版通过保留的 update-index 兼容入口升级到本版后使用新机制
- 镜像和默认更新源仍为 ghcr.io/lsmallice/codex-proxy-rs 与 lsmallice/codex-proxy-rs，不自动切回官方，不自动升级现有实例
