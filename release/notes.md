# v3.41.1

## 升级事项

- 本版本为 `lsmallice/codex-proxy-rs` 的二开发行，基于上游 v3.41.0；从 v3.41.0 升级没有新增数据库迁移，插件宿主合同保持不变
- WS 握手恢复默认关闭，迁移后需在持久化配置中显式开启；不承诺恢复所有 403，也不会绕过明确的权限拒绝
- 首次切换请备份数据库、配置及插件数据，保留现有网络、代理、资源限制和数据挂载，仅替换应用发行物。CPR 仍按单副本部署，重启会中断尚未完成的请求

## WS 握手恢复

- 新增 `openai.ws_opening_recovery`：仅处理 OAuth 新请求在发送业务正文前遇到的空正文 WebSocket 握手 403，保持同一账号、凭据和代理
- 可配置额外重试次数 0–5 次及等待间隔 50–5000 毫秒，默认额外重试 2 次、间隔 200 毫秒；有效 `Retry-After` 优先，超过 5 秒则保留错误，不提前重试
- 重试耗尽后，仅在原生协议允许时尝试一次原生 HTTP/SSE；最终失败保留错误，不循环换号或切回 WS。请求截止时间和取消继续生效
- 明确权限错误、非空拒绝正文、API Key 账号、预热、旧响应续接和已发送正文的请求不适用；诊断时间线记录本策略的重试和降级

## 二开安装与更新

- 安装脚本和默认在线更新源使用 `lsmallice/codex-proxy-rs`，发行镜像使用 `ghcr.io/lsmallice/codex-proxy-rs`
- 完整发行包保留二进制、管理页面、宿主封口清单与 SHA-256 校验；沿用原生插件兼容检查和回滚流程
- 首次部署后可从管理端更新后续二开发行。网页更新不改写宿主机 Compose 镜像标签，更新后仍须同步持久化镜像版本，避免重建容器回到旧程序
- 沿用上游构建、测试、安全扫描和多平台发行校验，补充更新源、打包及安装入口回归检查
