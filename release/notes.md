# v3.41.2

## OpenAI 账号模型白名单

- 修复原生 Responses 请求被模型目录拦截的问题。OpenAI OAuth 或 API Key 账号的白名单精确包含映射后的上游模型 ID 时，即使目录尚未收录，也会允许该账号向上游请求，由上游确认是否可用
- 升级后已有白名单自动生效。目录外模型的放行只对配置该 ID 的账号生效，混合号池中的其他账号仍按各自的模型限制和有效目录选号

## 管理端

- 编辑账号时分组展示自定义模型和上游目录。搜索到已有模型时可直接勾选，输入未匹配的有效 ID 时可点击「添加模型」或按回车添加。全选和取消全选只作用于当前搜索命中的上游目录项
- 账号连接测试可以选择白名单中的自定义模型，方便验证指定账号能否实际调用该模型
- 请求健康卡片分别展示已取消和未完成的请求数。悬停图表可查看对应时段的服务成功率，缺少有效样本时显示「无有效样本」

## 二开能力与升级

- 本仓库沿用 `lsmallice/codex-proxy-rs` 安装与更新源，以及 `ghcr.io/lsmallice/codex-proxy-rs` 发行镜像，不切换到官方原版
- 保留默认关闭的 `openai.ws_opening_recovery`：仅恢复 OAuth 新请求发送正文前的空正文 WS 握手 403，使用同账号、同凭据、同代理进行有界重试；协议允许时沿用原生 HTTP/SSE 降级
- 明确权限错误、非空拒绝正文、API Key 账号、预热、旧响应续接及已发送正文的请求不因该开关放宽恢复范围
- 完整发行物继续执行校验、插件兼容检查和原生回滚。切换前备份数据库、配置和插件数据，保留数据挂载；网页更新后仍需同步 Compose 镜像版本，重启会中断在途请求
