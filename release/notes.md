# v3.49.1

## 新增功能

- 合并官方 v3.49.0：支持 Claude Messages 与 Token 计数、独立额度窗口调度系数、Key 显式预算窗口和多条预热 Cron
- 账号额度：支持通用额度窗口停调阈值与低周额度主动重置
- 管理端：支持 PWA 安装及桌面窗口标题栏，补齐 Intel macOS 安装包

## 优化改进

- 保留原生并发交接、独占 IPv6 自动分配、按插件配置最低 5 秒维护周期及二开设置页
- 保留 Lite 请求兼容、可配置模型冷却、空正文握手 403 恢复、WS 前导恢复及备用预连接
- 模型目录按账号持久化并保留排除设置，统一全局客户端画像与小时级版本检查
- 减少统计投影临时写入，改进 WebSocket 背压资源释放、消息大小协商和 Responses 身份隔离

## 问题修复

- 账号列表显示交接中的临时并发上限并标记“交接”，并发明细保留原始配置和适用范围说明
- 老号结束或取消交接后恢复原上限展示，新号不因展示修复被限制并发
- 对齐官方 Responses 输出参数归一化，不重新补回已省略的输出上限

## 升级须知

- 包含四项追加数据库迁移，升级前备份数据库、配置、运行数据和 Redis 持久卷，不支持直接降回旧程序
- 保留二开已发布的 IPv6 迁移编号和校验和，官方后续迁移顺延；二开与官方已迁移数据库不能直接混用
- 旧时间式账号预热按官方迁移关闭并清空，需按新 Cron 配置重新启用
- 更新运行设置的客户端需适配 accountWarmupCron 和完整 quotaResetWindowWeights 对象，窗口系数全为 0 时沿用默认排序
- 发往 Responses 上游的请求省略输出 Token 上限，实际输出可能超过客户端指定值
- 未绑定代理或绑定代理被禁用时使用部署代理环境变量，部署时核对 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY 和 NO_PROXY
- 本次仅发布主程序及 ghcr.io/lsmallice/codex-proxy-rs:3.49.1，不更新补号插件，不升级或重启线上实例
